AGENTS.md

  • Instructions your agent reads every session
AGENTS.md
-Be concise. No fluff.
-Strict scope: only what's asked. No refactoring.
-Read-only unless explicitly told to edit.
-Honest critique. Don't just agree.
-TDD: tests before implementation.
-Verify: run the tests before saying it's done.
-Match existing style. No new dependencies.
-Never commit secrets or credentials.
-Cite sources. Say so when unsure.
