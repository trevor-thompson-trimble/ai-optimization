AGENTS.md & SKILL.md

  • AGENTS.md — repo-level instructions the agent always reads
  • SKILL.md — a packaged, reusable capability the agent can load on demand

Example Layout

repo/
  AGENTS.md
  .copilot/
    skills/
      my-skill/
        SKILL.md
        scripts/
          helper.py

Example SKILL.md

---
name: my-skill
description: Use when the user asks to format a report.
---

# My Skill

1. Read the input file.
2. Apply the report template.
3. Write the output next to the input.

Creating Your Own Skills

  • Start from a real, repeated task you do with the agent
  • Write the steps down as a short SKILL.md
  • Refine after watching the agent actually use it

Finding Skills Online

  • Public skill repositories (e.g. community GitHub repos)
  • Copy, read, and adapt — don't trust blindly

Useful MCP Servers

  • GitHub — issues, PRs, repo search
  • Browser/web fetch — pulling live docs or pages into context
  • Project-specific servers (databases, ticketing, internal tools)
